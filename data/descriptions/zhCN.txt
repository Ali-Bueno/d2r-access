流亡者营地 [1] = 这座营地不过是一堆勉强遮风挡雨的破旧帐篷和马车。只有寥寥几名盲眼姐妹会的成员从覆灭的修道院逃到这里，如今只能与牛和鸡共处在这片凄凉之地。

Hangman's Tree = 埋骨之地中央矗立着一棵高大枯萎的树。腐烂的尸体悬挂在枝头，死者在树下蹒跚游荡。

精华荒地 [2] = 这片沼泽般的荒野一望无际，点缀着低矮的灌木和扭曲的枯树。曾经这里唯一的危险是凶猛的刺毛鼠，如今亡灵和成群的沉沦魔对任何愚蠢地离开流亡者营地庇护的人都是严重的威胁。

邪恶洞穴 [8] = 阿卡拉让你来这个阴森的地方是对的。刚到入口，你就能听到无数怪物不停的啁啾，它们正准备洗劫流亡者营地。但这里还潜伏着别的东西。死亡的，或者说不死的恶臭，沉沉地悬在空气中。

埋骨之地 [17] = 这座被遗忘的墓地已经荒废，小小的墓室和精致的铁栅栏正在崩塌生锈。亡者已经复活，在怪诞的绞刑树下蹒跚徘徊，准备把毫无防备的来客撕成碎片。

寝陵 [19] = 这座阴暗的地下墓穴里满是无名亡者的遗骸、被遗忘的财宝和凶残的亡灵。寻宝者，当心了！

墓穴 [18] = 除了焚烧昔日流亡者尸体的火光，没有一丝光线能穿透这座坟墓的阴影。这里也许有宝藏，但肯定有饥饿的恐怖在等着，随时要撕碎粗心的闯入者。
#
冰冷之原 [3] = 这一带被遗弃的农舍，诉说着种植庄稼、饲养牲畜的朴素年代。如今迪亚波罗的大军占据了这些田野，到处是堕落成恶魔的流亡者、亡灵和沉沦魔。

洞穴一层 [9] = 多年来没有人踏入这个被遗弃的地洞。谁知道里面扎下了什么恐怖的根？

洞穴二层 [13] = 阳光从未照到洞穴的这一部分。你不禁想，是谁让火把一直亮着？

石块旷野 [4] = 庇护所里藏着许多力量之地。在这片乱石遍地的荒原上，一圈古老的石环高高耸立。没有人确切知道它曾经意味着什么，或者这里举行过什么样的异教仪式。

崔斯特姆 [38] = 崔斯特姆只剩下一堆燃烧的可悲废墟，被追随迪亚波罗而来的怪物淹没。

地下通道二层 [14] = 洞穴这一段的空气潮湿而陈腐。你很确定这里没有通往地表的路，只有更多不得安息的怪物渴望你的血肉。

黑暗森林 [5] = 把这一片零落的可怜树木称作森林，已算慷慨。但它仍然充满了恶魔的生机。在它的中央某处，难觅踪迹的艾尼弗斯之树正等着被重新发现。

洞坑一层 [11] = 崔斯特姆周围布满了这样黑暗无底的洞穴。坎都拉斯的矿工们在挖什么？更重要的是，他们找到它时，唤醒了什么？

洞坑二层 [15] = 这个洞到底有多深？你希望下面除了令人不安的岩层、噼啪作响的火把和更多怪物之外，还有别的东西。

深坑一层 [12] = 变形的石墙似乎从四面八方向你逼近，你小心翼翼地深入这座不见天日的迷宫。

深坑二层 [16] = 你清醒地意识到，头顶不到一臂之遥压着无数吨岩石。只需一次地震或一场意外的爆炸，就会把你活埋在这里，永远与以这黑暗深坑为家的恐怖关在一起。

黑色沼泽 [6] = 刺骨的阵风像幽灵无形的手抚过你的脸。远处，一座倒塌高塔的残破树桩隐隐耸立，正召唤着你，就像当年召唤所有被女伯爵诱入死地的无辜少女一样。

被遗忘的高塔 [20] = 叫嚷着要女伯爵偿命的愤怒暴民，把这间地窖洗劫一空。只有东南角还剩几只被踹坏的木桶。环顾四周，你注意到西北方的墙上有个豁开的大洞，看上去非常新。从粗糙的毛石碎块坠落的样子，你意识到有人，或者有什么东西，从下面隐藏的地牢中冲了出来。

高塔地窖二层 [22] = 你深入女伯爵的迷宫。可怕的液体从凹凸不平的墙上滴落，烛光在深红的水洼中闪烁，也映在等着把你撕碎的怪物的眼中。

高塔地窖三层 [23] = 你拖着疲惫酸痛的身体越陷越深，脚步在嵌入地面的褪色大理石板上发出空洞的回响。仿佛不断加重的血腥味还不够糟，你又经过死去流亡者燃烧的尸体，焚烧血肉的刺鼻恶臭让你更难挤出呼喊的气力。

高塔地窖四层 [24] = 你几乎无法呼吸。嘴唇上有血的味道。是你的吗？还是你为了抵达又一片崩塌的大厅和燃烧的走廊，而剖开的最后一只羊头人的内脏？那里回荡着幽灵般追击者空洞的笑声。

高塔地窖五层 [25] = 通道突然敞开，把你吐进一片奢华与暴行交织的怪异喧嚣之中。前方，你看到一只淫靡镀金的大盆，满溢着静止的鲜血。巨大的火把让环绕女伯爵浴池的两排柱子投下疯狂舞动的影子，随着她嘲弄的笑声扭动。

泰摩高地 [7] = 盲眼修道院气势逼人的高墙耸立在风吹的高地上。它看似坚不可摧，一想到那支大军轻蔑而轻易地攻陷它并把姐妹们赶出去，你就不寒而栗。随后一个更冷的念头袭来：现在轮到你去攻打这座设防的礼拜堂了。

修道院大门 [26] = 你小心翼翼地踏入修道院大门朴素的柱廊，到处都是战斗的痕迹。断裂的武器、翻倒的烛架和深红的血迹，讲述着一个骇人的故事。
#
外侧回廊 [27] = 你来到一座壮丽的庭院，无处不在的战斗痕迹几乎没有损害它的美。中央有一座华美的喷泉，三名背靠背的流亡者举着武器，抵挡着看不见的敌人。
#
营房 [28] = 庭院宁静的恢弘之后，营房是一座混乱的迷宫，蜿蜒的走廊、被洗劫的宿舍和杂乱的储藏室交错。成排的木桶为占据此地的众多敌人提供了绝佳的藏身处。谁能找到正确的路，更别说找到那间放着附魔锤子的小铁匠铺了？

监牢一层 [29] = 这座地下穹室巨大、黑暗而寒冷。野蛮的刑具一览无余。你不禁疑惑，姐妹们在这底下做什么？囚犯们现在又在哪里？
#
监牢二层 [30] = 你的脚步声在墙壁间空洞地回响。这地方到底有多大？你走过的牢笼，足够关下一座小镇的人口。而监牢还在更深处延伸。

监牢三层 [31] = 一种几乎有形的绝望气息渗透了这里。没有光，没有希望，只有早已死去的囚犯腐朽的遗骸。

内侧回廊 [32] = 再次看到开阔的天空，你松了一口气。你已来到回廊的核心。前方，你看到盲眼大教堂高耸的尖塔。

地下墓穴二层 [35] = 这一层地下墓穴看上去比上一层古老得多。供人反思的场所不见了，取而代之的是空白的墙壁和安放亡者的空房间。

地下墓穴三层 [36] = 数百年的尘埃覆盖着这里的每一处表面，使得恶魔的利爪惊扰亡者的地方格外显眼。被惊醒的亡者如今将怒火倾泻到恶魔和闯入者身上。

地下墓穴四层 [37] = 安达莉尔的存在把大地本身扭曲成了地狱的景象。参差扭曲的骨刺刺穿大地，留下张着大口、浸满鲜血的深坑。空气中弥漫着硫磺和更为恶心的东西的恶臭。

鲁·高因 [40] = 鲁·高因是一座围绕热闹集市的小港口城镇，在无情的沙漠烈日下炙烤。怪物接连不断的袭击，迫使居民躲在家中瑟瑟发抖。只有勇敢或绝望的人才敢踏上它的鹅卵石街道，更别说城外的碎石荒野了。
#
下水道一层 [47] = 你一走进下水道，浓烈的恶臭就重重地袭来，堵在喉咙里。这远远超出了你熟悉的垃圾与污物的腐臭。一种沉重病态的甜腻附着在空气中，仿佛某种不自然的瘟疫直接渗入了滑腻的砖块和生锈的格栅，而它们正勉强拦着这座城市的污秽。
#
下水道二层 [48] = 你的嗅觉在下水道第一层的半途就已投降，所以过了一会儿你才意识到恶臭变了。那已不再只是你已经习惯的、令人作呕的垃圾和酸性毒物的混合气味。如今，毫无疑问的腐烂气息渗进了这杯地狱鸡尾酒。你咬紧牙关继续前进。也许击败潜伏在这座地狱般蓄水池底部的怪物，终于能让这股腐臭散去。
#
下水道三层 [49] = 这里无疑是下水道最深的地方。古老的砖石在数百年的重压下弯曲，一想到透过生锈破碎的格栅所见的浑浊液体里可能潜伏着什么，你就不寒而栗。你咒骂那些早已死去的蠢货，当初竟觉得把古老的邪恶埋在一座活着的城市下面是个好主意。
#
碎石荒野 [41] = 沙漠夺走的远不止鲁·高因周围的沃土。看着数十具干枯的尸体被捆在木桩上，鲜红的军服被晒褪了色，沾满沙子和干涸的血迹，你意识到荒野对这座城市的人民同样征收了残酷的代价。
#
碎石古墓一层 [55] = 这座半埋的坟墓的阴影拥抱了你，厚重的砂岩轻易挡住了外面无情的酷热，你松了一口气。直到在回声阵阵的走廊里小心走出几步，你才意识到自己并不孤单。远远不是。这座坟墓充满了亵渎的生机，居住者们怀着盲目的目的，向你蹒跚走来。
#
碎石古墓二层 [59] = 古老贵族逝去的辉煌弥漫在坟墓的这一层。就连亡灵也穿着适合朝臣和仆人的华服，是对生前生活的空洞嘲弄。你只能希望深入碎石古墓能给你带来他们失去的财富的一小部分。
#
干燥高地 [42] = 在碎石荒野灼热的沙漠中跋涉已经十分艰辛，如今地势向上倾斜，每前进一步都更加费力。回头不是选项。你必须找到隐藏在这些干燥山丘间的亡者大殿，这里到处是饥饿的猛兽。
#
亡者大殿一层 [56] = 你说不准哪个更糟：外面灼人的沙漠酷热，还是这座被神遗弃的陵墓中寒入骨髓的潮湿空气。仅存的几支噼啪燃烧的火把只提供微弱的光，阴影带着不死的威胁扭动。
#
亡者大殿二层 [57] = 恐怖的浪潮不会退去。你找到了通往大殿更深处的台阶，但亡灵仍源源不断地涌来，饥饿的呻吟在褪色的壁画墙壁和崩塌的雕像间回荡。
#
亡者大殿三层 [60] = 你能感觉到一股神秘的暗流充满空气。赫拉迪姆魔盒一定就在这里的某处，藏在这座由坚硬岩石开凿而成、满是噩梦的迷宫深处。

偏远绿洲 [43] = 这片沙漠地带充满生机。泉水滋养着茂盛的棕榈，为你遮挡阳光，也孕育出成群吸血的昆虫。然后，灌木丛中有什么橙色的、马一般大小的东西动了起来。

蛆虫巢穴一层 [62] = 你把身体挤过一个窄得离谱的洞口，来到一座满是黏液、令人窒息的巢穴，里面是错综复杂、爬满虫子的隧道。黏液从墙上滴落，凝结成厚厚的薄片，覆盖在相邻的隧道上。

蛆虫巢穴二层 [63] = 隧道无尽地延伸。黏液渗入你的衣服和靴子，让每一步都成为吱吱作响的噩梦。在这疯狂缠绕、令人窒息的通道深处，等着的是创造这些隧道的怪物。

蛆虫巢穴三层 [64] = 你已深入蜂巢最深处，居住者的抵抗明显变强了。无论它们在守卫什么，你都会找到并将其毁灭。

失落之城 [44] = 曾经温馨的房屋被掏空的废墟，从数十年前吞没它们的沙子中探出头来。成群的野蛮怪物沿着狭窄的小巷和荒芜的大道追踪着你。

古代水道 [65] = 好奇心带你走进你以为是干涸、被沙子填满的隧道，但令你沮丧的是，你误入了又一座肮脏、恶臭熏天的蓄水池，里面住着臭气熏天的强盗和腐烂的亡灵。

群蛇峡谷 [45] = 蛇形雕像分列在精致的神殿入口两侧，沐浴在摇曳的火把光中。空气中带着干皮革的气味，你听见愤怒的利爪蝮蛇疯狂的嘶嘶声。

利爪蝮蛇神殿一层 [58] = 你下到利爪蝮蛇的地下巢穴，决意一劳永逸地打断它们不可名状的仪式。守卫们嘶嘶地吐着唾沫，冲上来阻止你！

利爪腹蛇神庙二层 [61] = 神殿中心的污秽祭坛，是利爪蝮蛇降临大地的那股不自然黑暗的源头。

女眷住处一层 [50] = 你下到一座装饰奢华的房间迷宫。异国香水的缕缕香气撩拨着你的鼻孔，与你身后那些肮脏的坟墓和下水道形成刺耳的对比。轻薄的丝绸被随意丢弃在地毯上。房间气派，却空无一人……生命骤然消失的寂静震耳欲聋。

女眷住处二层 [51] = 仍然跪在楼梯脚下的无头守卫并不令人意外，只是阴郁的确认。地狱的军团抢先一步来到这里。从地板上积成一摊摊的黏稠血迹看，它们没有留下任何幸存者。

王宫监牢一层 [52] = 后宫被洗劫的奢华让位于实用的储藏室和酒窖。出乎意料，大部分补给完好无损。地狱的军队显然对椰枣、肉干或陈年美酒不感兴趣。
