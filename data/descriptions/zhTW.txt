# Act I
#
俠盜營地 [1] = 這座營地不過是一堆勉強遮風擋雨的破舊帳篷和馬車。只有寥寥幾名目盲之眼姐妹會的成員從覆滅的修道院逃到這裡，如今只能與牛和雞共處在這片淒涼之地。
#
Hangman's Tree = 埋骨之地中央矗立著一棵高大枯萎的樹。腐爛的屍體懸掛在枝頭，死者在樹下蹣跚遊蕩。
#
鮮血荒地 [2] = 這片沼澤般的荒野一望無際，點綴著低矮的灌木和扭曲的枯樹。曾經這裡唯一的危險是兇猛的針刺鼠，如今亡靈和成群的沉淪魔對任何愚蠢地離開俠盜營地庇護的人都是嚴重的威脅。
#
邪惡洞窟 [8] = 阿卡拉讓你來這個陰森的地方是對的。剛到入口，你就能聽到無數怪物不停的啁啾，它們正準備洗劫俠盜營地。但這裡還潛伏著別的東西。死亡的，或者說不死的惡臭，沉沉地懸在空氣中。
#
埋骨之地 [17] = 這座被遺忘的墓地已經荒廢，小小的墓室和精緻的鐵柵欄正在崩塌生鏽。亡者已經復活，在怪誕的絞刑樹下蹣跚徘徊，準備把毫無防備的來客撕成碎片。
#
大陵墓 [19] = 這座陰暗的地下墓穴裡滿是無名亡者的遺骸、被遺忘的財寶和兇殘的亡靈。尋寶者，當心了！
#
墓地 [18] = 除了焚燒昔日俠盜屍體的火光，沒有一絲光線能穿透這座墳墓的陰影。這裡也許有寶藏，但肯定有飢餓的恐怖在等著，隨時要撕碎粗心的闖入者。
#
冰冷之原 [3] = 這一帶被遺棄的農舍，訴說著種植莊稼、飼養牲畜的樸素年代。如今迪亞布羅的大軍佔據了這些田野，到處是墮落成惡魔的俠盜、亡靈和沉淪魔。
#
洞穴第一層 [9] = 多年來沒有人踏入這個被遺棄的地洞。誰知道裡面紮下了什麼恐怖的根？
#
洞穴第二層 [13] = 陽光從未照到洞穴的這一部分。你不禁想，是誰讓火把一直亮著？
#
亂石曠野 [4] = 庇護所裡藏著許多力量之地。在這片亂石遍地的荒原上，一圈古老的石環高高聳立。沒有人確切知道它曾經意味著什麼，或者這裡舉行過什麼樣的異教儀式。
#
崔斯特姆 [38] = 崔斯特姆只剩下一堆燃燒的可悲廢墟，被追隨迪亞布羅而來的怪物淹沒。
#
地底通道第一層 [10] = 一進入你就意識到這個迷宮般的洞穴系統有多龐大，無數死路和蜿蜒的通道裡擠滿了躁動不安的恐怖。沒有人能保證你能活著穿過。
#
地底通道第二層 [14] = 洞穴這一段的空氣潮溼而陳腐。你很確定這裡沒有通往地表的路，只有更多不得安息的怪物渴望你的血肉。
#
黑暗森林 [5] = 把這一片零落的可憐樹木稱作森林，已算慷慨。但它仍然充滿了惡魔的生機。在它的中央某處，難覓蹤跡的艾尼弗斯之樹正等著被重新發現。
#
地洞第一層 [11] = 崔斯特姆周圍佈滿了這樣黑暗無底的洞穴。坎杜拉斯的礦工們在挖什麼？更重要的是，他們找到它時，喚醒了什麼？
#
地洞第二層 [15] = 這個洞到底有多深？你希望下面除了令人不安的岩層、噼啪作響的火把和更多怪物之外，還有別的東西。
#
地穴第一層 [12] = 變形的石牆似乎從四面八方向你逼近，你小心翼翼地深入這座不見天日的迷宮。
#
地穴第二層 [16] = 你清醒地意識到，頭頂不到一臂之遙壓著無數噸岩石。只需一次地震或一場意外的爆炸，就會把你活埋在這裡，永遠與以這黑暗深坑為家的恐怖關在一起。
#
黑色荒地 [6] = 刺骨的陣風像幽靈無形的手撫過你的臉。遠處，一座倒塌高塔的殘破樹樁隱隱聳立，正召喚著你，就像當年召喚所有被女伯爵誘入死地的無辜少女一樣。
#
遺忘之塔 [20] = 叫嚷著要女伯爵償命的憤怒暴民，把這間地窖洗劫一空。只有東南角還剩幾隻被踹壞的木桶。環顧四周，你注意到西北方的牆上有個豁開的大洞，看上去非常新。從粗糙的毛石碎塊墜落的樣子，你意識到有人，或者有什麼東西，從下面隱藏的地牢中衝了出來。
#
高塔地牢第一層 [21] = 進入地窖更深的幾層，血腥的金屬味衝擊著你的鼻腔。低頭一看，你的腳正踩在一灘看起來剛流出的鮮血中。這怎麼可能？看上面那堆可悲的廢墟，女伯爵應該在幾百年前就已經死了。
#
高塔地牢第二層 [22] = 你深入女伯爵的迷宮。可怕的液體從凹凸不平的牆上滴落，燭光在深紅的水窪中閃爍，也映在等著把你撕碎的怪物的眼中。
#
高塔地牢第三層 [23] = 你拖著疲憊痠痛的身體越陷越深，腳步在嵌入地面的褪色大理石板上發出空洞的迴響。彷彿不斷加重的血腥味還不夠糟，你又經過死去俠盜燃燒的屍體，焚燒血肉的刺鼻惡臭讓你更難擠出呼喊的氣力。
#
高塔地牢第四層 [24] = 你幾乎無法呼吸。嘴唇上有血的味道。是你的嗎？還是你為了抵達又一片崩塌的大廳和燃燒的走廊，而剖開的最後一隻羊頭人的內臟？那裡迴盪著幽靈般追擊者空洞的笑聲。
#
高塔地牢第五層 [25] = 通道突然敞開，把你吐進一片奢華與暴行交織的怪異喧囂之中。前方，你看到一隻淫靡鍍金的大盆，滿溢著靜止的鮮血。巨大的火把讓環繞女伯爵浴池的兩排柱子投下瘋狂舞動的影子，隨著她嘲弄的笑聲扭動。
#
泰摩高地 [7] = 目盲之眼修道院氣勢逼人的高牆聳立在風吹的高地上。它看似堅不可摧，一想到那支大軍輕蔑而輕易地攻陷它並把姐妹們趕出去，你就不寒而慄。隨後一個更冷的念頭襲來：現在輪到你去攻打這座設防的禮拜堂了。
#
修道院大門 [26] = 你小心翼翼地踏入修道院大門樸素的柱廊，到處都是戰鬥的痕跡。斷裂的武器、翻倒的燭架和深紅的血跡，講述著一個駭人的故事。
#
外側迴廊 [27] = 你來到一座壯麗的庭院，無處不在的戰鬥痕跡幾乎沒有損害它的美。中央有一座華美的噴泉，三名背靠背的俠盜舉著武器，抵擋著看不見的敵人。
#
兵營 [28] = 庭院寧靜的恢弘之後，營房是一座混亂的迷宮，蜿蜒的走廊、被洗劫的宿舍和雜亂的儲藏室交錯。成排的木桶為佔據此地的眾多敵人提供了絕佳的藏身處。誰能找到正確的路，更別說找到那間放著附魔錘子的小鐵匠鋪了？
#
監牢第一層 [29] = 這座地下穹室巨大、黑暗而寒冷。野蠻的刑具一覽無餘。你不禁疑惑，姐妹們在這底下做什麼？囚犯們現在又在哪裡？
#
監牢第二層 [30] = 你的腳步聲在牆壁間空洞地迴響。這地方到底有多大？你走過的牢籠，足夠關下一座小鎮的人口。而監牢還在更深處延伸。
#
監牢第三層 [31] = 一種幾乎有形的絕望氣息滲透了這裡。沒有光，沒有希望，只有早已死去的囚犯腐朽的遺骸。
#
內側迴廊 [32] = 再次看到開闊的天空，你鬆了一口氣。你已來到迴廊的核心。前方，你看到目盲之眼大教堂高聳的尖塔。
#
大教堂 [33] = 再溫暖的燭光，也掩蓋不了施加在這座禮拜堂上的肆意暴行。屍體像被隨手丟棄的玩具一樣散落，倒在哪裡就腐爛在哪裡，曾經潔淨的大理石地面上積起了血泊。
#
地下墓穴第一層 [34] = 走廊兩側排列著紀念姐妹們受人尊敬的亡者的華麗棺木，在其間你驚訝地發現舒適的藏書室、冥想室和其他供人反思的場所，如今都被安達莉爾劫掠的大軍徹底玷汙。
#
地下墓穴第二層 [35] = 這一層地下墓穴看上去比上一層古老得多。供人反思的場所不見了，取而代之的是空白的牆壁和安放亡者的空房間。
#
地下墓穴第三層 [36] = 數百年的塵埃覆蓋著這裡的每一處表面，使得惡魔的利爪驚擾亡者的地方格外顯眼。被驚醒的亡者如今將怒火傾瀉到惡魔和闖入者身上。
#
地下墓穴第四層 [37] = 安達莉爾的存在把大地本身扭曲成了地獄的景象。參差扭曲的骨刺刺穿大地，留下張著大口、浸滿鮮血的深坑。空氣中瀰漫著硫磺和更為噁心的東西的惡臭。

# Act II
#
魯高因 [40] = 魯高因是一座圍繞熱鬧集市的小港口城鎮，在無情的沙漠烈日下炙烤。怪物接連不斷的襲擊，迫使居民躲在家中瑟瑟發抖。只有勇敢或絕望的人才敢踏上它的鵝卵石街道，更別說城外的碎石荒地了。
#
下水道第一層 [47] = 你一走進下水道，濃烈的惡臭就重重地襲來，堵在喉嚨裡。這遠遠超出了你熟悉的垃圾與汙物的腐臭。一種沉重病態的甜膩附著在空氣中，彷彿某種不自然的瘟疫直接滲入了滑膩的磚塊和生鏽的格柵，而它們正勉強攔著這座城市的汙穢。
#
下水道第二層 [48] = 你的嗅覺在下水道第一層的半途就已投降，所以過了一會兒你才意識到惡臭變了。那已不再只是你已經習慣的、令人作嘔的垃圾和酸性毒物的混合氣味。如今，毫無疑問的腐爛氣息滲進了這杯地獄雞尾酒。你咬緊牙關繼續前進。也許擊敗潛伏在這座地獄般蓄水池底部的怪物，終於能讓這股腐臭散去。
#
下水道第三層 [49] = 這裡無疑是下水道最深的地方。古老的磚石在數百年的重壓下彎曲，一想到透過生鏽破碎的格柵所見的渾濁液體裡可能潛伏著什麼，你就不寒而慄。你咒罵那些早已死去的蠢貨，當初竟覺得把古老的邪惡埋在一座活著的城市下面是個好主意。
#
碎石荒地 [41] = 沙漠奪走的遠不止魯高因周圍的沃土。看著數十具乾枯的屍體被捆在木樁上，鮮紅的軍服被曬褪了色，沾滿沙子和乾涸的血跡，你意識到荒野對這座城市的人民同樣徵收了殘酷的代價。
#
古老石墓第一層 [55] = 這座半埋的墳墓的陰影擁抱了你，厚重的砂岩輕易擋住了外面無情的酷熱，你鬆了一口氣。直到在回聲陣陣的走廊裡小心走出幾步，你才意識到自己並不孤單。遠遠不是。這座墳墓充滿了褻瀆的生機，居住者們懷著盲目的目的，向你蹣跚走來。
#
古老石墓第二層 [59] = 古老貴族逝去的輝煌瀰漫在墳墓的這一層。就連亡靈也穿著適合朝臣和僕人的華服，是對生前生活的空洞嘲弄。你只能希望深入古老石墓能給你帶來他們失去的財富的一小部分。
#
乾土高地 [42] = 在碎石荒地灼熱的沙漠中跋涉已經十分艱辛，如今地勢向上傾斜，每前進一步都更加費力。回頭不是選項。你必須找到隱藏在這些乾燥山丘間的死亡之殿，這裡到處是飢餓的猛獸。
#
死亡之殿第一層 [56] = 你說不準哪個更糟：外面灼人的沙漠酷熱，還是這座被神遺棄的陵墓中寒入骨髓的潮溼空氣。僅存的幾支噼啪燃燒的火把只提供微弱的光，陰影帶著不死的威脅扭動。
#
死亡之殿第二層 [57] = 恐怖的浪潮不會退去。你找到了通往大殿更深處的臺階，但亡靈仍源源不斷地湧來，飢餓的呻吟在褪色的壁畫牆壁和崩塌的雕像間迴盪。
#
死亡之殿第三層 [60] = 你能感覺到一股神秘的暗流充滿空氣。赫拉迪姆方塊一定就在這裡的某處，藏在這座由堅硬岩石開鑿而成、滿是噩夢的迷宮深處。
#
遙遠的綠洲 [43] = 這片沙漠地帶充滿生機。泉水滋養著茂盛的棕櫚，為你遮擋陽光，也孕育出成群吸血的昆蟲。然後，灌木叢中有什麼橙色的、馬一般大小的東西動了起來。
#
蛆蟲巢穴第一層 [62] = 你把身體擠過一個窄得離譜的洞口，來到一座滿是黏液、令人窒息的巢穴，裡面是錯綜複雜、爬滿蟲子的隧道。黏液從牆上滴落，凝結成厚厚的薄片，覆蓋在相鄰的隧道上。
#
蛆蟲巢穴第二層 [63] = 隧道無盡地延伸。黏液滲入你的衣服和靴子，讓每一步都成為吱吱作響的噩夢。在這瘋狂纏繞、令人窒息的通道深處，等著的是創造這些隧道的怪物。
#
蛆蟲巢穴第三層 [64] = 你已深入蜂巢最深處，居住者的抵抗明顯變強了。無論它們在守衛什麼，你都會找到並將其毀滅。
#
失落古城 [44] = 曾經溫馨的房屋被掏空的廢墟，從數十年前吞沒它們的沙子中探出頭來。成群的野蠻怪物沿著狹窄的小巷和荒蕪的大道追蹤著你。
#
古代通道 [65] = 好奇心帶你走進你以為是乾涸、被沙子填滿的隧道，但令你沮喪的是，你誤入了又一座骯髒、惡臭熏天的蓄水池，裡面住著臭氣熏天的強盜和腐爛的亡靈。
#
群蛇峽谷 [45] = 蛇形雕像分列在精緻的神殿入口兩側，沐浴在搖曳的火把光中。空氣中帶著幹皮革的氣味，你聽見憤怒的利爪蛇魔瘋狂的嘶嘶聲。
#
利爪蛇魔神殿第一層 [58] = 你下到利爪蛇魔的地下巢穴，決意一勞永逸地打斷它們不可名狀的儀式。守衛們嘶嘶地吐著唾沫，衝上來阻止你！
#
利爪蛇魔神殿第二層 [61] = 神殿中心的汙穢祭壇，是利爪蛇魔降臨大地的那股不自然黑暗的源頭。
#
後宮第一層 [50] = 你下到一座裝飾奢華的房間迷宮。異國香水的縷縷香氣撩撥著你的鼻孔，與你身後那些骯髒的墳墓和下水道形成刺耳的對比。輕薄的絲綢被隨意丟棄在地毯上。房間氣派，卻空無一人……生命驟然消失的寂靜震耳欲聾。
#
後宮第二層 [51] = 仍然跪在樓梯腳下的無頭守衛並不令人意外，只是陰鬱的確認。地獄的軍團搶先一步來到這裡。從地板上積成一攤攤的黏稠血跡看，它們沒有留下任何倖存者。
#
皇宮地窖第一層 [52] = 後宮被洗劫的奢華讓位於實用的儲藏室和酒窖。出乎意料，大部分補給完好無損。地獄的軍隊顯然對椰棗、肉乾或陳年美酒不感興趣。
#
